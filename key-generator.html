Algorithm reference
Key format: FNDBY-SEG1-SEG2-SEG3
SEG1 = toSeg( fnv1a32(seed + ":S1") )   SEG2 = toSeg( fnv1a32(seed + ":S2") )
SEG3 = toSeg( fnv1a32("FNDBY" + SEG1 + SEG2) ) ← checksum
toSeg(n) encodes a uint32 as 4 chars from A–Z0–9 (base-36, big-endian).
Validation only checks the SEG3 checksum — it does not require the original seed.
