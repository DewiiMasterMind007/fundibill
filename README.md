# Invoicy

A desktop invoicing app for small businesses — built with Electron, React, and sql.js.

---

## Development

### Prerequisites
- [Node.js](https://nodejs.org/) v18 or later
- npm v9 or later

### Install dependencies

```bash
npm install
```

### Run in dev mode

```bash
npm run dev
```

This starts the Vite dev server on `http://localhost:5173` and launches Electron simultaneously. Hot-reloading is active for the React frontend. Changes to `electron/` require a manual restart.

---

## Building the Windows installer

### One command

```bash
npm run build:win
```

This will:
1. Generate `assets/icon.ico` if it doesn't already exist (placeholder — replace it before distributing)
2. Compile the React frontend with Vite → `dist/renderer/`
3. Package everything with electron-builder → `dist/Invoicy-Setup-1.0.0.exe`

### Output

| File | Description |
|------|-------------|
| `dist/Invoicy-Setup-1.0.0.exe` | Self-contained Windows installer |

### What the installer does
- Installs Invoicy to `C:\Program Files\Invoicy`
- Creates a **Desktop shortcut**
- Creates a **Start Menu** entry under *Invoicy*
- Registers an uninstaller (visible in *Apps & features*)
- Silent / one-click install — no wizard screens

---

## Replacing the app icon

Place your own `.ico` file at:

```
assets/icon.ico
```

Recommended: **256×256 px**, exported as a multi-resolution `.ico` containing 16, 32, 48, and 256 px sizes. The file generated by `npm run build:win` when no icon exists is a 32×32 placeholder and should be replaced before distributing.

A quick way to convert a PNG to ICO: [icoconvert.com](https://icoconvert.com) or install `png-to-ico` via npm.

## Project structure

```
Invoicy App/
├── assets/              # Build resources (icon.ico goes here)
├── electron/
│   ├── main.js          # Electron main process
│   ├── preload.js       # Context bridge (exposes window.db to renderer)
│   ├── database.js      # sql.js database layer
│   └── license.js       # License key validation
├── src/                 # React frontend (compiled by Vite)
│   ├── pages/           # Dashboard, Invoices, Estimates, Clients, Items, Settings
│   ├── components/      # Sidebar, trial banner, license modal
│   └── pdf/             # @react-pdf/renderer PDF generation
├── scripts/
│   └── create-icon.js   # Placeholder icon generator
├── electron-builder.yml # Packaging configuration
├── vite.config.js       # Vite build configuration
└── package.json
```

---

## Data storage

User data (invoices, clients, settings) is stored in a local SQLite file:

```
%APPDATA%\Invoicy\invoicy.db
```

This file is **not deleted** on uninstall, so your data is safe if you reinstall.
